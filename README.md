# Starter Kit: Patungan (Angular)

Project Angular polos untuk latihan template. Sudah berisi:

- Angular 22 (standalone, signals), Bootstrap 5 (sudah dipasang di `angular.json`)
- `@angular/forms` sudah terpasang (dipakai untuk `ngModel`)
- `src/app/data/menu.ts`: tipe `Item`, 5 item contoh (fiktif), jumlah orang, dan persen pajak
- `src/app/app.config.ts`: bahasa Indonesia untuk pipe `currency`, `percent`, dan `date`
- `src/app/app.ts` dan `app.html`: hanya judul "Patungan"

Komponen (`src/app/components/`) kamu buat sendiri mengikuti panduan PDF.

Cara pakai (butuh Node.js 22.22.3+ atau 24.15+ untuk Angular CLI 22):

    npm install
    npm start

Lalu buka http://localhost:4200.
